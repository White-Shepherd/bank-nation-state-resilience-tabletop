# Resilience ecosystem map guide

**SYNTHETIC EXERCISE DATA - NOT A REAL BANK**

Use Board view first, then select a service and expand layers. Search and filters operate on declared nodes and relationships; nothing is inferred. Node positions are deterministic by layer and identifier. A click or the synchronized selector opens owner, authority, Tier 0 rationale, dependencies, monitoring, warning, tolerances, recovery, limitations, state, and decisions. Scenario time reveals only states declared in `scenario_states.yaml`.

Plotly was selected because its actively maintained Python package supports deterministic coordinates, Streamlit interaction, standalone HTML, and documented PNG/SVG export. Static export uses Kaleido and a compatible Chrome installation. The graph always has a tabular fallback.
