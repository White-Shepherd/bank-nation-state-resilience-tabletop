# Recording checklist

## Before

- [ ] Rehearse once without recording; restart the application.
- [ ] Run preflight; load synthetic Harbor Ridge data; reset Demo Mode.
- [ ] Close personal applications; hide bookmarks, paths, usernames, and browser profile data.
- [ ] Disable desktop, browser, calendar, chat, phone, and recording-app notifications.
- [ ] Set 1920×1080 or higher, 30 fps, browser zoom 100%, visible cursor.
- [ ] Select and test the microphone; record and review ten seconds of speech.
- [ ] Prepare water, script, board PDF, and backup output directory.

## During

- [ ] Pause two seconds between sections and leave silence around mistakes.
- [ ] Move the cursor deliberately; zoom only to direct attention.
- [ ] Explain what changed and why it matters; do not read the screen verbatim.
- [ ] Distinguish synthetic evidence, computed behavior, judgment, and limitations.
- [ ] Restate each decision, owner, deadline, and uncertainty at the transition.

## After

- [ ] Preserve and back up the raw master before editing.
- [ ] Record pickups and clean screenshots; export the demonstrated reports.
- [ ] Log branch, commit, application version, runtime, and recording date.
- [ ] Create and proof captions; inspect every frame for sensitive information.
- [ ] Confirm claims against `evidence-index.md` and archive the privacy review.
