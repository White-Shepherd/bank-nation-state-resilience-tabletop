# Four-hour exercise design

**SYNTHETIC EXERCISE DATA - NOT A REAL BANK**

The six phases total 240 minutes and 30 injects. Phase 0 tests posture, monitoring, freezes, privilege, backup, and coordination. Phase 1 tests correlation, escalation, declaration, preservation, hunting, and Tier 0 protection. Phase 2 tests crisis activation, prioritization, workarounds, obligations, communication, notification, and authority. Phase 3 tests availability versus integrity, suspension, authoritative data, reconciliation, evidence, and messaging. Phase 4 tests acceptance, isolation, minimum viable banking, liquidity, legal/regulatory escalation, and board involvement. Phase 5 tests clean-room recovery, sequencing, validation, reconciliation, restoration criteria, monitoring, and remediation.

Facilitators reveal evidence progressively, require a decision card for consequential choices, distinguish facts from assumptions, record dissent, and do not reward fast restoration without integrity evidence. Counsel/compliance owns jurisdiction-specific notification analysis. Suggested roles and major decisions are implemented in the application. Exercise success is evidence of disciplined decisions and identified improvements, not a decorative score.
