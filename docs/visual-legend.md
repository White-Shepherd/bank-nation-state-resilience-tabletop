# Visual legend

**SYNTHETIC EXERCISE DATA - NOT A REAL BANK**

Shape plus label identifies layer: square/rounded square = service, process, application or data; hexagon = infrastructure; diamond = security; filled circle = internal player; outlined circle = external player. Recovery is stated in the accessible label and detail panel. Tier 0 nodes are larger with thick borders. Text markers state `[FAILED]`, `[DEGRADED]`, `[RESTORED]`, `[WARNING]`, `[UNKNOWN]`, or `[NORMAL]`; color is never the only cue. Dashed relationships are dependencies, dotted lines are monitoring/escalation, and dash-dot lines are recovery. Zoom and reset controls are keyboard accessible where Streamlit/Plotly supports them.
