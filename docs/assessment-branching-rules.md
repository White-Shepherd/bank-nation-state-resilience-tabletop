# Assessment Branching Rules

| Trigger | Wizard behavior | Result |
|---|---|---|
| No manual workaround | Skip unavailable detail | Create a resilience gap when supported |
| Third party supports service | Request provider, access, recovery, contract, and substitution evidence | Provider dependency review |
| Recovery uses production identity | Request independent identity evidence | Recovery-independence review |
| Service processes payments | Request settlement, payment, and liquidity tolerances | Payment-specific tolerance review |
| Authoritative data unclear | Do not assume authority | Evidence-gap item |
| Tool deployed but untested | Request validation evidence | No effectiveness credit |
| Dependency supports multiple services | Examine explicit relationships | Concentration review |

Rules only reveal questions or review items. They do not invent dependencies, automatically propagate failure, or make risk decisions.
